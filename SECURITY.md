# Reporting security issues

Please report suspected vulnerabilities privately to [hello@mobekk.blog](mailto:hello@mobekk.blog).
Include the affected URL or file, reproduction steps, and the likely impact. Avoid posting
credentials, personal information, or exploit details in public issues.

The supported version is the current source on `main`. Security fixes are published
through the validated GitHub Pages deployment workflow.

For local builds and the remaining hosting/account controls, see
[docs/security.md](docs/security.md).
